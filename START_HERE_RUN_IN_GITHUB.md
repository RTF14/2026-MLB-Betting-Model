# Start Here: Run In GitHub

## Run Tomorrow's Predictions

Open this link:

[Run Tomorrow's Predictions](https://github.com/RTF14/2026-MLB-Betting-Model/actions/workflows/run-tomorrows-predictions.yml)

Then:

1. Click `Run workflow`
2. Click the green `Run workflow` button
3. Wait for it to finish
4. Click the completed run
5. Read the predictions table on the run page

Latest saved table:

[View Latest Predictions](https://github.com/RTF14/2026-MLB-Betting-Model/blob/main/Run%20Tomorrow%27s%20Predictions/latest_predictions.md)

## Run Historical Tests

Open this link:

[Run Historical Tests](https://github.com/RTF14/2026-MLB-Betting-Model/actions/workflows/run-historical-tests.yml)

Then:

1. Click `Run workflow`
2. Leave `include_odds_history` as `true`
3. Click the green `Run workflow` button
4. Wait for it to finish
5. Click the completed run
6. Read the dashboard table on the run page

Historical dashboard:

[View Historical Dashboard](https://github.com/RTF14/2026-MLB-Betting-Model/blob/main/Historical%20Test%20Results/outputs/dashboard.md)

## If You Do Not See Run Workflow

Make sure you are signed into GitHub as `RTF14`.

Open the repo:

[2026 MLB Betting Model](https://github.com/RTF14/2026-MLB-Betting-Model)

Then open:

[Actions](https://github.com/RTF14/2026-MLB-Betting-Model/actions)

If GitHub shows a message that workflows are disabled, click the button to
enable workflows for the repository.
